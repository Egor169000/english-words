# Мои слова — как добавлять слова

Это офлайн-приложение (PWA) для английских слов пользователя (Георгий). Оно хостится на GitHub Pages:
https://egor169000.github.io/english-words/ — ветка `main`, корень репозитория.

## Где что лежит
- `words.json` — единственный источник слов. Приложение скачивает его при запуске, когда есть сеть.
- `tools/add_words.js` — добавляет/обновляет слова в `words.json`.
- `tools/build_docx.js` — собирает Word-файл «Мой английский словарь.docx» из `words.json`.
- Word-файл живёт у пользователя на Mac: `/Users/georgy/Desktop/Study/англ. яз./Мой английский словарь.docx`.
- Прогресс повторения хранится только на телефоне (localStorage), в репозитории его нет.
- Карточка в приложении и Word-файл показывают только слово, перевод и пример (так попросил пользователь).
  Транскрипцию, часть речи, перевод примера и заметки всё равно заполняй: они видны в разделе «Словарь».

## Как добавить слова, которые прислал пользователь
1. Для каждого слова приведи его к словарной форме и заполни поля:
   - `word` — слово или выражение (глаголы-фразы с `to`, если так естественнее: `to come up with`);
   - `ipa` — британская транскрипция в слэшах: `/juːˈbɪk.wɪ.təs/`;
   - `pos` — часть речи по-русски: `сущ.`, `гл.`, `прил.`, `нареч.`, `фраз. гл.`, `предл.`, `союз`, `выраж.`, `идиома`;
   - `tr` — русский перевод, главное значение первым, 1–3 варианта через запятую;
     если пользователь дал контекст, первым ставь значение из этого контекста;
   - `ex` — короткий естественный пример, слово в примере выделено звёздочками: `She *came up with* a plan.`;
   - `exRu` — перевод примера;
   - `ctx` — где встретил (только если пользователь сказал);
   - `note` — по желанию: важные формы, неправильные глаголы, частые сочетания;
   - `from` — только для слов из приложения (см. ниже): слово ровно так, как оно написано в сообщении.

   **Слова из приложения.** В приложении можно добавить слово самому; кнопка «Отправить Claude» присылает
   сообщение вида `Добавь в «Мои слова»:` и список `- слово — перевод (встретил: «предложение»)`
   (перевода и предложения может не быть). Заполни все поля как обычно (перевод пользователя бери за основу,
   предложение — в `ctx`) и обязательно поставь `from` с исходным написанием, например `"from": "evolved"`
   для записи `to evolve`. По `from` приложение узнаёт слово и убирает свою локальную копию, сохраняя прогресс.

   **Замена.** Пометка `(заменить старую карточку; …)` значит, что пользователь заменил в приложении уже
   существующее слово. В новом JSON укажи новые `word`/`tr`/`ex` и т.д. и `"replace": true`.
   `add_words.js` обновит старую запись и проставит `edited`, по нему приложение уберёт локальную замену.

   **Дубликаты.** Пользователь просил проверять каждое присланное слово на дубликаты.
   Сначала приведи слово к словарной форме (evolved → to evolve), потом запусти скрипт: он не добавит слово,
   которое уже есть, и выведет блок «Дубликаты» с текущим переводом. В ответе перечисли дубликаты
   («surge — уже есть: резкий рост, всплеск») и спроси: оставить старое или заменить новым.
   Если скажет заменить — повтори для этих слов с `"replace": true`.
   Слова с пометкой «заменить старую карточку» из приложения — это уже его решение, их заменяй сразу.
2. Запиши новые слова массивом в файл вне репозитория и выполни
   `node tools/add_words.js /путь/new.json words.json`.
3. Собери Word-файл: `NODE_PATH=$(npm root -g) node tools/build_docx.js words.json "/путь/Мой английский словарь.docx"`
   (нужен npm-пакет `docx`) и положи его в папку пользователя (через device_commit_files или device_bash).
4. Закоммить и запушь `words.json` в `main`. Pages обновится за минуту-две; телефон подтянет слова при следующем запуске с сетью.
5. Ответь коротко: какие слова добавлены (слово — перевод), какие оказались дубликатами, сколько всего.

Не меняй `app.js`/`sw.js` без просьбы. Если меняешь оболочку приложения, увеличь `VERSION` в `sw.js`.
