# Мои слова

Офлайн-приложение для английских слов: карточки с интервальным повторением (коробки Лейтнера), тест и словарь с поиском.

**Открыть:** https://egor169000.github.io/english-words/

## Установка на телефон
- **iPhone:** открой ссылку в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** открой ссылку в Chrome → ⋮ → «Установить приложение».

После установки приложение работает без интернета. Новые слова подтягиваются автоматически, когда телефон в сети.

## Как это устроено
- `words.json` — список слов. Его пополняет Claude, когда ему присылают новые слова.
- Прогресс повторения хранится на самом устройстве. В настройках приложения есть резервная копия прогресса.
- `tools/build_docx.js` собирает из `words.json` Word-файл «Мой английский словарь».
